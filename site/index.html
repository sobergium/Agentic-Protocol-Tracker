04 / Atomicity comparison

There is no free atomicity.

Each model protects a different participant. None makes an arbitrary service and an external ledger a single atomic operation.

A

Authorization-first

Verify → Serve → Settle

Fast fulfillment. The merchant carries collection risk when service succeeds but settlement fails.

Risk owner · Merchant
B

Upfront

Verify → Settle → Serve

Collection certainty. The payer needs refund and remediation when service later fails.

Risk owner · Payer
C

Escrow

Lock → Serve → Release

Narrows exposure, but introduces locked funds, release authority and dispute states.
